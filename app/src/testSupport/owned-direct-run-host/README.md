# Pinned Direct callback/error host tests

Only the build coordinator runs this suite, after compiling the exact current main/test classes. Use the same environment variables and manifest contract as `webm-paired-host/run.sh`, then:

bash app/src/testSupport/owned-direct-run-host/run.sh REPO EXTERNAL_OUTPUT

This suite instantiates pinned `SequenceAssetLoader` with a capturing test factory and drives pinned `ExoPlayerAssetLoader.PlayerListener.onPlayerError` on a bounded host HandlerThread. That real Media3 path creates the asynchronous ExportException wrapper, forwards it to the actual private Direct/Editor Transformer listeners, and drains the actual shared runner algorithm.

It uses the production registered attempt/pair and deterministic existing syscall fixture. Reflection sets captured engine/pair/session identities and the working phase for negative callback testing. The poison-window tests additionally replace only the fixture exact token's retained-object queue with an observation-preserving subclass. It retains the actual object, then pauses after production files.poisoned publication until the real runner waiting thread catches its actual checkpoint failure. The test checkpoint wrapper can only wait/observe and rethrows the exact production exception; it never supplies a failure. No production test hook or alternate runner is added. It never writes the original-failure slot, successful outcome, source EOF, observer observations, resource seals or durable proof. The concrete Engine is allocated without invoking an Android Context constructor because these private listener/shape functions have no Context dependency. This does not test successful owner-run issuance.

Covered failures include input cancellation/deadline/plain IO/identity; blocked input/output IO followed by cancellation/deadline; actual output storage-full/identity/force failure; late completion; native unsupported; unregistered nested cause; unchanged Editor mapping; native error before later bounded OUTPUT finalization IO; known-rejected OUTPUT open versus unknown open, deterministic RAW/OUTPUT syscall poison windows (plain IO, cancellation, deadline, invalid write progress, unknown-open mapping, throwing close, native-first then mutation), actual completion dependents outside the attempt monitor, and release UNCONFIRMED separate from primary. Existing paired tests must also be rerun, particularly original WebmCallerFailure preservation through Matroska/parserBoundary.

No Android decode, real ExoPlayer loading, real Transformer export, codec cleanup, converted playback, durable finish or publication is established. Actual native ordering and the successful one-pass silent run still require the approved native fixture gate. Opus audible-boundary and typed finish/adoption/verification remain separate required work.
