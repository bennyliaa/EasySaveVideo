# Remaining independently selectable work

No next milestone is started by this handoff.

## Deferred B2 native identity bridge

The bounded origin, final-media outcome boundary and generic event API are present,
but the app cannot yet prove that a selected page candidate equals the provider's
video identity. Native video SAVED and PLAYED therefore remain UNKNOWN. Future work
must identify a defensible existing identity/signal contract, with explicit failure
and stale-navigation behavior; it must not guess URLs or reinterpret page provenance
as video identity. A missing trustworthy bridge is an honest partial result.

## M8-B3 — Bounded power policy and admitted filters

Implement only a pure injected battery/thermal/network policy initially. Inputs may
only tighten existing foreground/visibility/round/watermark bounds and Save/Record
priority. No permanent poller or background worker. Source choices may expose only
already admitted namespaces and truthful unsupported/unknown metadata. Count-only
statistics create no demand. OS wiring and measured energy behavior remain separate.

## M9-A — Ordinary fixed Commons reliability matrix

Fault-inject only the already admitted fixed Commons transport/cache/coordinator:
unreachable/slow source, malformed/oversized/partial metadata, cancellation at commit,
stale/exhausted/incompatible cursors, storage unavailable, one source failure and
zero sources. Preserve independent Browser + Save availability. Use existing host
persistence adapters and deterministic bounded recovery, strict exact74 checks and
full source/bundle cold reruns. This is not blocked rule-interpreter stress.
