When separately authorized, verify:

- Restore genuine prior local discovery state and preserve rights/history/progress.
- Each sort, history policy and page-size combination preserves the current page;
  slow/late sources affect only later pages. Unknown dates/durations remain unknown.
- Source labels remain readable in narrow phone, tablet, orientation, accessibility
  font scaling and the currently admitted SkinKit theme; no screenshot claim exists.
- After separate Save/Record task-state wiring is implemented, rapid foreground/
  background and task-priority changes stop physical work,
  preserve progress and do not manufacture provider failures on resume.
- Invalid keyboard/IME input does not strand a valid search.
- Process interruption and actual SQLite/disk failures preserve prior data and do not
  show successful sorting/history/reset messages.
- Real Commons source limitations, exhausted cursor behavior and service backoff.
- Battery, thermal, networking and energy measurements. Concurrency budgets and
  host tests are not a claim of measured energy savings or Android compatibility.

Long-term history capacity management, all-history controls and reliable played/
saved event wiring remain separate M8 follow-on development work. Browser fallback,
normal MediaLibrary and Save/Record behavior remain their own existing acceptance
tracks. Vault and remote rule/runtime acceptance are separately blocked.
