## 1. 验收原则

1. 每项关键需求必须具有可重放的输入、操作、预期结果和证据。
2. 正常链路与异常链路同等重要；“不会无限等待、不会损坏已有文件、能继续操作”是共同断言。
3. 测试以自有或明确允许测试的媒体为主；真实站点兼容性另列，不把某站短期失效等同 Core 不可用。
4. 模拟器用于UI/逻辑/兼容性，真机用于录制、音频、硬件编码、权限、生物识别与后台行为。
5. 不承诺全站保存。受保护内容应正确拒绝，而不是以绕过成功作为通过标准。
6. 以实际运行记录区分 `PASS / FAIL / BLOCKED / NOT_RUN / NOT_APPLICABLE`；禁止将“设计支持”写成 PASS。
7. 本文数值门槛属于 v0.3 工程验收起点；M0/M7 可凭测量校准并记录，不能默默降低门槛。

## 2. 测试层级与环境

```text
Specification测试向量
       |
       +--> 单元测试：去重 / 四策略 / Gate / 状态机 / 坐标变换
       +--> 契约测试：Provider / Platform / Store / Package
       +--> 集成测试：DB+文件提交 / Downloader / Recorder / Recovery
       +--> 端到端：搜索或URL -> 原网页 -> ①②③ -> MP4 -> 库
       +--> 故障注入：断网 / 超时 / crash / 磁盘满 / kill / 更新中断
       +--> 真机与发布验证：API差异 / 音频 / 加密 / 日志 / 商店
```

| 维度 | 最低覆盖 | 目的 |
|---|---|---|
| Android API | API30、API35；发布时受支持最新稳定API另增 | 保住最低版本与新行为兼容 |
| 设备 | Pixel 7/API35基线，API30环境，至少另一厂商真机 | 编码器/权限/后台差异 |
| WebView | 记录精确版本，至少两组实际支持版本 | renderer/媒体行为差异 |
| 屏幕 | 竖屏、横屏、小屏、大屏/平板布局 | 网格、选区、Insets、旋转 |
| 网络 | Wi-Fi、移动网络、断网、慢网、重连、限流 | 有界重试与续传 |
| 存储 | 充足、接近满、写入中满、外部目录权限撤销 | 文件提交与恢复 |
| 权益 | 免费、Save Pro、Tools、Provider Plus、总包、过期、未知 | 统一Gate与免费Vault |
| 构建 | Debug/Internal/Release、零Provider构建 | 不带测试解锁、不漏日志 |

每次报告记录：app commit、Specification版本、SDK/工具链、设备/API、WebView、依赖版本、网络配置、样本ID和时间。涉及用户数据的截图/文件不得自动上传；验收使用合成非敏感样本。

### 5.2 四策略确定性测试向量

预置六条同一 SearchProfile 数据：A=仅DISCOVERED；B=SHOWN；C=OPENED+SHOWN；D=PLAYED+OPENED+SHOWN；E=SAVED但未SHOWN/OPENED/PLAYED；F=完全新发现。排序测试固定相关度相同，使用稳定ID作为tie-break。

| 测试ID | 策略 | 必须出现/顺序 | 必须排除 |
|---|---|---|---|
| T-H01 | PREFER_NEW | A/E/F在B/C/D之前；不足可补旧 | 仅排本会话重复 |
| T-H02 | HIDE_WATCHED | A/B/E/F | C/D |
| T-H03 | HIDE_SHOWN | A/E/F | B/C/D |
| T-H04 | SHOW_ALL | A/B/C/D/E/F各一次 | 当前结果集重复副本 |
| T-H05 | 未真实可见的预取卡片 | 仅DISCOVERED，不生成SHOWN | 不允许预取即标已看 |
| T-H06 | 当前页卡片变为SHOWN后返回上一页 | 已物化页可回看；不再次分配到新页 | 不允许当前页瞬间消失 |

`SAVED` 不自动等于“看过”；测试向量刻意覆盖该情况。播放无法可靠确认时只记录OPENED。

## 6. 故障注入矩阵

共同检查：UI仍可操作、任务能取消或到终态、无无限重试、其他域继续、既有媒体不损坏、日志无敏感信息。每行分别在操作前/进行中/提交临界点注入适用故障。

| 故障ID | 注入方式 | 预期隔离/恢复 | 必查数据不变量 |
|---|---|---|---|
| FI-01 | 网络中途断开，随后恢复 | 有界退避或等待；恢复后核验checkpoint | 不重复/拼错字节，Discovery后台不重启 |
| FI-02 | Provider永久不响应 | deadline取消，其他来源继续，熔断 | pool/cursor不前移到未接收页 |
| FI-03 | Provider错误JSON/缺字段/超大体 | 拒绝该响应，来源局部失败 | 无内存膨胀、无原正文日志 |
| FI-04 | Provider重复cursor/全重复页 | 请求预算耗尽后cooldown | 无无限循环；当前卡片不重复 |
| FI-05 | Provider429/限流 | 遵守有界Retry-After，不请求风暴 | 其他源仍可用 |
| FI-06 | WebView renderer crash | 重建受影响标签/renderer组 | 已独立保存任务不被误取消 |
| FI-07 | 下载/编码写入时磁盘满 | 安全失败/等待释放空间，不盲目降级 | 旧文件有效；临时项可辨认 |
| FI-08 | 目录URI/媒体权限变化 | 重新授权提示、保留内部产物 | 不写未授权路径、不删除原件 |
| FI-09 | 数据库损坏/迁移中断 | 隔离问题库，恢复或安全模式 | 不重建空库覆盖Vault和长期历史 |
| FI-10 | 缓存损坏 | 删除可重建缓存并继续 | 用户媒体不被当缓存删除 |
| FI-11 | Direct50%中断/源ETag变化 | 同源才能续传，否则重启该任务 | 不拼接两个不同资源 |
| FI-12 | HLS分片消失/缺音轨 | 重试到上限失败或用户重新选择 | 不发布缺轨/缺片成功产物 |
| FI-13 | Projection被系统停止 | 安全关闭捕获和编码，提示原因 | 无后台幽灵录制，无复用旧授权 |
| FI-14 | AudioCapture不可用 | 明示静音或终止由用户决定 | 不启用未同意麦克风 |
| FI-15 | Encoder抛错/native故障 | 隔离/进程重启后恢复检查 | 已验证Segment不丢，不阻塞浏览器恢复 |
| FI-16 | Merge/Crop/Compress中kill | 恢复或清理未提交输出 | 原片存在且内容不变 |
| FI-17 | Save提交前/指针替换后/DB提交后kill | journal对账、幂等收敛 | 单一有效MediaItem，无悬空成功记录 |
| FI-18 | Provider包下载一半中断 | 旧版活动，staging可清理 | active pointer不指向半包 |
| FI-19 | Provider包验签/激活/cleanup中kill | 完整新包或有效LKG | 不执行篡改/部分规则 |
| FI-20 | Provider新版解析连续失败 | 有界健康判定回滚；坏版本隔离 | 不反复升级回滚振荡 |
| FI-21 | 错签名/密钥撤销/旧包重放 | 拒绝，保留安全旧版或停用 | rollback不能绕过安全版本下限 |
| FI-22 | Vault加密/移入/导出中kill | 清理明文、恢复完整对象或隔离 | 锁定时无可见私密内容 |
| FI-23 | Keystore密钥失效 | 明确不可解密状态，保留密文与恢复选择 | 不生成新空密钥假装修复 |
| FI-24 | 日志磁盘满/日志文件坏 | 丢弃日志或重建限额文件 | 主功能不因日志失败崩溃 |
| FI-25 | Store超时/重复交易/退款 | 权益状态稳定，免费功能继续 | 不重复授予、不删除媒体 |
| FI-26 | 取消后迟到success/旧epoch回调 | 丢弃不匹配回调 | 终态和新Session不被覆盖 |
| FI-27 | 低内存/热限制/低电量 | 降并发、暂停Discovery或安全停止编码 | 无无限重启任务风暴 |
| FI-28 | Recipe路径穿越/恶意regex/重定向内网 | Runtime拒绝并有界退出 | 不访问任意文件/内网/凭证 |

故障注入必须覆盖 `prepare -> execute -> verify -> atomic commit/replace -> cleanup` 每个阶段，而不是仅在下载过程中断网。文件与数据库之间的崩溃窗口需分别验证。

## 7. 日志与隐私验收

| 测试ID | 操作 | 通过条件 |
|---|---|---|
| T-P01 | 用独特诱饵关键词/URL/标题执行正常业务 | Release日志/Logcat/App诊断无这些值；正常业务不产流水 |
| T-P02 | Cookie/Token/PIN/密码/密钥诱饵触发异常 | 无敏感值；异常message/堆栈也不泄漏 |
| T-P03 | Provider返回带私密字段的错误正文 | 日志只有安全错误码/版本，不保留结果 |
| T-P04 | 多次技术错误超过日志限额 | 单文件<=1MiB，总<=5MiB，7天到期清理 |
| T-P05 | 拒绝导出日志、断网使用 | 无默认上传请求；功能正常 |
| T-P06 | Debug网络库/第三方SDK输出审计 | Debug同样不记录敏感凭证/私密内容 |
| T-P07 | 全部无痕/Vault流程、最近任务/备份检查 | 无普通历史/缩略图/明文副本泄漏 |
| T-P08 | 清Seen History与清缓存 | 仅删除目标功能数据；媒体/Vault完好 |

查看数据库中必要的 SeenRecord 不属于日志泄漏，但必须验证仅本地持久化、用户可清理、无痕例外正确。测试报告不得为了证明脱敏而附上真实用户秘密。

## 8. 性能与输出质量门槛

| 指标 | 初始验收目标 | 测法 |
|---|---|---|
| Provider结束 | 单次15秒deadline内结束或安全取消 | 故意不响应服务+时钟控制 |
| 后台Discovery | 立即禁新请求，2秒内在途取消 | 抓取测试网络请求，不记录真实用户流量 |
| 高水位空闲 | 库存>=H且无主动更新时10分钟零Provider请求 | 固定池与可控时钟 |
| UI可操作 | 错误/取消1秒内有状态反馈 | 控制网络/编码阻塞，UI操作测试 |
| 翻页 | 本地已物化页p95<=200ms，基线设备 | 固定缓存、重复测量并记录分布 |
| 大文件内存 | 1GiB样本内存不随文件体积线性增长 | 与100MiB样本峰值比较、查全量缓冲 |
| 长录制 | 30分钟样本无持续资源增长/崩溃 | 真机、温度/内存记录、结束资源回收 |
| 音画同步 | 测试样本偏差目标<=100ms | 时间码+蜂鸣对齐，首/中/尾测量 |
| 拼接时长 | 20秒+30秒成片50秒，误差<=0.5秒 | 容器duration与实际解码比对 |
| 拼接接缝 | 无引入的明显黑帧/长停顿 | 帧检查；黑帧来源内容与处理区分 |
| 选区准确 | 合成标尺样本偏差<=2输出像素 | 考虑编码偶数对齐，记录实际输出尺寸 |
| Recovery启动 | 轻检查目标2秒内让地址栏可操作 | 大量孤立临时文件时长扫描异步 |
| 终态一致 | 所有注入用例零永久RUNNING/无限loading | 等待deadline后检查UI+DB+后台资源 |

若设备能力导致无法达到目标，应提供测量、可见降级与规格修订建议，不能仅删除测试。网络首屏耗时依赖来源，单独报告本地开销与网络耗时，不设“全网任意查询固定秒数”承诺。

## 9. 原子更新验收状态表

| 被杀位置 | 允许重启结果 | 禁止结果 |
|---|---|---|
| prepare之前 | 无新任务产物 | 孤立成功媒体记录 |
| execute期间 | 原件完整，新临时项可恢复/清理 | 半文件替换原件 |
| verify失败 | 原件完整，失败输出隔离 | 未验证产物对外可见 |
| commit意图已记但文件未切换 | 幂等继续或回滚 | DB永久指向不存在文件 |
| 文件已切换但DB未提交 | Recovery补齐索引或安全还原 | 重复入库、删除唯一有效新文件 |
| DB已提交但cleanup未做 | 正常媒体可见，清理无引用临时项 | 清理时误删新主文件 |
| 外部导出中断 | 内部主产物保留，外部失败可清理 | 把失败导出当作全部保存失败并删原件 |

此表同时用于媒体处理、Vault移动、Provider激活和数据库迁移的对应事务边界；各类不共用一个盲目删除临时文件的通用脚本。
