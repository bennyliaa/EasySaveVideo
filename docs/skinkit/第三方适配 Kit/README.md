# 第三方适配 Kit

此文件夹供第三方宿主 App 适配和集成 SkinKit 使用。

- `SkinKit-Closed-SDK-0.3.0-recovery-r1.zip`：SDK 二进制集成包，不含 SDK 实现源码；包内提供依赖、集成资料及宿主示例源码。
- `SkinKit Ready 开发规范 V1.0.md`：适配流程、接口约束与验收要求。
- `SkinKit Default Theme UI Design Specification V1.0.md`：默认主题的视觉与交互规范。

当前 SDK 为 0.3.0-recovery-r1 测试候选，不代表正式 1.0.0 发布。规范标题中的 V1.0 是文档版本，实际验证范围以父目录的设备验收报告为准。

父目录的演示 APK 仅供查看效果和辅助验收，无需打包进宿主 App。三份原始资料的字节内容未改动，APK 和 SDK 内嵌资源未重打包。
