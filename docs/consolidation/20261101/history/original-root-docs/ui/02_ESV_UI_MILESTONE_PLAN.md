# EasySaveVideo UI 实现里程碑

版本：V1.0｜日期：2026-10-11｜PPT32｜总目标：UI-E可签收

## 1. 工作方式

新增UI-A～UI-E与现有功能开发并行。源码AGENTS记录Update的M0～M12已替代旧里程碑次序，保留正式现行编号；原M0～M9仅作历史来源。本包不宣称原功能Gate通过。功能未完成不阻断对应页面搭建，使用契约化模拟；真实功能完成后替换Adapter。预计工作量与日期由Coder核实正式基线后填写，不在本文编造天数。

UI-B和UI-C可在UI-A已确认的区域并行推进；新增依赖未准入前使用不需新依赖的规格、资源、适配和组件设计工作。UI-D按垂直流程分批，不等待全部页面完成才接真实功能。

## 2. UI-A：基线与接入盘点

**输入**：本交付包、正式仓库、既有功能与依赖证据。

工作：

1. 记录工作目录、分支、提交、未提交变更、构建变体及现有验证命令。
2. 逐功能/动作登记真实、部分、未开发、不可用；确认真实接口和完成证据。
3. 盘点SkinKit、EsvTheme、Compose桥接、导航、配置、图片、DI、任务、播放器；选择复用路径。
4. 归档后续API31决定及其替代原API30条款，核对正式仓库AGENTS与M0～M12里程碑版本。
5. 提交框架/依赖计划：坐标、版本、来源、校验、许可证、传递闭包、准入任务、替换成本。

**产物**：`ESV_UI_IMPLEMENTATION_BASELINE.md`、`ESV_UI_FRAMEWORK_REUSE_AND_DEPENDENCY_PLAN.md`、`ESV_UI_FEATURE_INTEGRATION_LEDGER.md`初版。

**退出**：正式基线可追踪，必要依赖已按现有机制准入；每项能力有绑定计划与所有者；API31决策及里程碑替代关系可查。出现正式仓库新决策冲突时记录影响范围，不阻断无关UI工作。

## 3. UI-B：默认主题、组件与国际化基础

**输入**：UI-A主题/依赖范围、PPT4/5/27/34。

工作：扩展同一Token Registry，保留完整Light/Dark默认；将现有快照映射为ESV视觉模型与Material3标准组件；补全部状态、语义和资源回退；建立语言资源、首期中文/英文、系统跟随入口；建立组件演示场景。

**最小垂直切片**：发现卡片+地址/搜索+保存选择Sheet，展示Light/Dark、中文/英文、200%字号、加载/错误/禁用/焦点。

**产物**：`ESV_UI_TOKEN_AND_COMPONENT_MAP.md`、组件实现、语言资源、主题完整性/资源租约测试、最小切片截图。

**退出**：必需Token完整，不以SafeDefaults掩盖漏项；同代快照一致；标准控件通过SkinKit视觉入口；关键按钮可达且无裁切；无页面硬编码公共视觉；换主题不创建第二套业务实例。

## 4. UI-C：统一导航与自适应页面框架

**输入**：UI-B基础组件、官方导航与窗口依赖。

工作：四主目的地、设置辅助入口、次级返回；七板块全部页面位置；Compact/Medium/Expanded与低高度布局；稳定ID选中与锚点恢复；正常/加载/空/错误/等待可达；模拟标签和确定性场景选择器仅Internal/测试可用。

**产物**：AppShell、目的地登记、七板块页面、场景数据集、初版PPT截图矩阵。

**退出**：所有目的地可达，手机和平板复用状态与业务逻辑；导航不依赖一串互斥布尔值形成隐式返回栈；旋转/窗口变化不重复命令；模拟无网络、真实写盘、真实购买或Projection副作用。

## 5. UI-D：按能力接真实功能

| 批次 | 垂直流程 | 接入关键点 | 退出证据 |
|---|---|---|---|
| D1 | 发现→原网页 | 结果/Seen/分页/Browser会话 | 原网页正确打开；后台/离开发现停止补充 |
| D2 | 检测→选择→保存→任务 | Gate/候选/幂等命令/领域任务 | 真实可用方式产物校验入库；未完成动作明确模拟 |
| D3 | 录制→片段→编辑 | 系统授权/停止/有效时长/非破坏输出 | 真机系统流程；有能力的动作真实通过，其他为占位 |
| D4 | 媒体库→私密→导出 | stableID/权限/加密/认证/副本 | 锁定不泄漏，导出不丢原件，模拟不计安全证据 |
| D5 | 设置→来源→外观语言→权益 | 存储/签名更新/locale/主题/Store | 配置重启保留、版本失败回退、免费能力独立可用 |

真实接口应转换为第05文档页面模型，不要求领域模块改造成UI模型。不创建另一个SaveCoordinator、录制控制器或Vault实现。

**产物**：真实Adapters、接入台账更新、异常映射、真实流程证据。源码约束中APK装配、安装等执行权限按正式仓库现行授权另行落实，本包不扩大；可先完成已允许的编译/lint/JVM/ABI检查并登记设备测试待执行。

**退出**：已开发且可调用能力真实接入；每个动作与数据源可核实；生产不会因真实失败转入Fake；活动任务在主题/语言/窗口变化后连续；领域语义不回退。

## 6. UI-E：效果与回归验收

工作：按第04文档运行行为、可访问性、主题、语言、窗口、性能及Release检查；按第07矩阵归档34页对应截图；对齐Token后建立首份真实Golden；修复阻断问题，记录系统页/网页/动态内容合理差异。

**产物**：`ESV_UI_TEST_REPORT.md`、`ESV_UI_PPT_ACCEPTANCE_MATRIX.md`、`ESV_UI_KNOWN_ISSUES.md`、`ESV_UI_HANDOFF_RECORD.md`，构建与截图证据目录。

**退出**：UI验收与已接真实功能验收分别有结论；P0/P1清零；无未说明缺页、未翻译关键文案或私密泄漏；模拟范围已签收；未实现真实能力不标为功能PASS。
