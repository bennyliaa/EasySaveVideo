# EasySaveVideo Tester UI 测试要求

版本：V1.0｜日期：2026-10-11｜关联：UI-R01～14、PPT1～34

## 1. 测试结论边界

测试分别记录：UI外观与交互、模拟场景、真实业务、发行隔离。模拟数据可以使UI场景PASS，不能使MP4、录制、密码加密、真实支付等业务PASS。未执行为NOT_RUN；能力未开发为DEMO_ONLY/NOT_IMPLEMENTED；不要填写无条件PASS。

现有功能测试与依赖准入检查继续执行，不能以UI截图替代。本文定义要求，不表示测试已运行。

## 2. 环境矩阵

| 维度 | 最低覆盖 | 备注 |
|---|---|---|
| Android | Android12/API31最低环境、Pixel7/API35、当前target对应代表环境 | API31依据ESV源码AGENTS后续决定；API36实机/模拟器按正式基线落实，API30不在本包默认支持范围 |
| 设备 | 手机、平板；录制/音频/编码真机 | 模拟器不证明捕获和编码能力 |
| 窗口 | Compact、Medium、Expanded；横竖屏、低高度、分屏 | 另检查窗口类别边界附近；折叠模拟检查遮挡 |
| 主题 | System、Light、Dark；无Core默认、已选Core有效/失败 | 仅验证正式选用模块，未选模块记录N/A |
| 语言 | 中文、英文、System、伪本地化长文/RTL | 完整RTL发行语言待冻结 |
| 字号 | 100%、200%及代表性中间值 | 关键操作、Sheet和系统键盘同时检查 |
| 数据 | 正常、加载、空、失败、离线、等待、中断 | 使用固定场景ID和样本 |
| 构建 | Internal/演示、Release | 生产不得存在任意Fake解锁 |

不要求每个页面跑完整笛卡尔积：所有页面至少手机/平板各一组；代表性流程交叉Light/Dark×中文/英文×Compact/Expanded；发现、保存Sheet、任务、录制、Vault、语言设置增加200%字号和异常状态。三类窗口转换与边界另测，不能只取两张理想截图。

执行范围遵守正式仓库授权；若APK装配/安装/设备步骤尚未获准，准备场景与用例并记NOT_RUN，不为交付测试报告越过该限制。本包不代表已授权真实账号、支付、商店发布或部署。最终业务验收仍需相应实际证据。

## 4. 自动化与手工分工

- JVM：页面Adapter、错误映射、修订号、防重、状态归约、格式化、模拟场景、Token完整性。
- Compose UI Test：导航、语义、按钮点击、Sheet、多选、空错恢复、语言与长文本；通过语义/稳定ID定位，避免依赖坐标点击。
- Android集成：locale与配置重建、WebViewHost、任务恢复、资源租约及授权入口。
- 真机：捕获授权、内部音频、编码、系统停止、私密认证、实际输出文件。
- 截图：冻结Token后真实UI Golden；概念图只作设计参照，不直接成为像素Golden。
- 性能：复用现有测量体系或准入官方工具，记录启动、列表滚动、图像加载、窗口/主题切换和相关峰值内存。报告设备、构建、场景、样本次数/分布；在UI-A冻结项目阈值，不在本文虚构FPS或内存已通过值。

## 5. 视觉与资源检查

同一数据集/页/字号/locale/窗口/主题抓图。检查信息层级、导航、主操作、面板、卡片、间距、圆角、Token颜色/状态、占位与长文本。正文普通文本对比度以4.5:1为基准；图片背景下必须实测文字保护。禁止用全局像素阈值忽略关键按钮、私密泄漏等功能缺陷。

系统授权窗口、第三方网页和动态媒体允许与概念图不同，必须记录原因；ESV自有控件不据此豁免主题/国际化要求。素材未许可不进入发行构建。

## 6. 问题分级与结果记录

P0：私密泄漏、错误认证/越权、用户媒体破坏、生产Fake授权、严重崩溃。P1：主流程不可达、任务重复/丢失、语言/窗口导致关键操作缺失、保存成功伪报、关键页缺失。P2：非阻断排版/视觉/翻译差异。P3：微小装饰与可接受优化。

验收必须P0/P1清零。P2/P3逐项记录接受人、理由、影响和后续安排，不由Tester自行全部忽略。
