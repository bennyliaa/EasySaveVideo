# Ordinary owned-page evidence: pre-implementation review

The frozen labels, bytes and hashes remain authoritative and unchanged. Review is against safety and evidence obligations, independently of benchmark scores; no claim of a second human reviewer is made.

Approved implementation scope: the same bounded structural predicate as B (one main, one visible video, no embeds, explicit legacy marker or a controlled sole main player). Ordinary pages do not need a test marker. A single safe source declaration establishes page evidence only. JSON-LD alone remains insufficient: a structured declaration may corroborate a player, but does not establish playback, extraction, rights or media identity. Ambiguous/ad/sidebar players, hidden ancestors, multiple sources, embeds and deleted players abstain.

DOM execution is constructor-admitted per exact owned path, separately from the existing exact XHR identity rule. DOM admission cannot coexist with an XHR rule. No rule comes from HTTP, downloaded selectors or scripts. Chromium fulfills the sole document from owned bytes, denies all other routes, cookies, permissions, downloads, frames and workers, and preserves sandbox/TLS. A fixed compiled selector waits for a controlled main player; DOM evidence has a distinct wire enum and requires dynamic consent. It does not claim XHR correlation. Limits and Windows Job cleanup remain unchanged.

Review outcome: proceed within owned fixtures. Public navigation, generic Chromium capability, Android dynamic execution and handset measurements remain unaccepted/unmeasured. Add adversarial structural tests, actual isolated DOM and existing XHR regression tests, strict protocol dynamic-consent tests, and preserve earlier results as historical baseline.
