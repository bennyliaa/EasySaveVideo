## 取证边界与原创素材

- 固定 UI 控件/标签/选中状态可验证；不采集私人标题、搜索、URL、目录或列表。
  如果工具只能生成整页截图/层级且可能包含用户内容，该自动化项 NOT_RUN；不能先读取
  再打码称为未读取。由用户手动确认固定 UI，或先建立获准的原创素材场景。
- 不打开私人视频/图片、缩略图、预览或用户草稿，不进入 Vault/规则/导入；不启用麦克风，
  不开始录屏，不改安全设置或防火墙，不操作其他应用/已有用户 URI 授权。
- 业务测试仅用专门准入的原创素材和测试文件夹/输出，记录自己的 ID/版本/哈希及操作。
  可使用已有原创合成8秒素材（191650 bytes，SHA256
  74c26a41fca18c585d288b51a8362381f23e4f0a34053df117630daa8720c353），但进入库必须通过
  已有合法发布流程；不新建导入功能、不写 DB 造 READY、不用私人媒体补足样本。
- 若当前允许的路径无法安全发布/识别原创素材，则业务项 NOT_RUN，先独立完成固定 UI。
  外部输出只核对该次原创操作实际拥有的 URI/文件，不枚举相册、DCIM 或用户文件目录。
